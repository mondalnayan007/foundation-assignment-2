# 🎬 MovieBuzz

**MovieBuzz** is a modern, responsive web application for movie and TV show enthusiasts. Users can browse trending titles, view detailed information, check ratings, and explore genres seamlessly across both desktop and mobile devices.

---

## ✨ Features

- 🍿 **Trending & Popular Showcase:** Browse top-rated movies and TV shows in real-time.
- 🍿 **Dynamic Search functionality:** User can search their charished Movies and TV Shows.
- 📱 **Fully Responsive Layout:** Optimized UI custom-tailored for mobile and desktop screens.
- 🔍 **Detailed Show Views:** View cast, ratings, release years, and clean plot summaries.
- 🎨 **Cinematic UI/UX:** Built with dark-mode aesthetic, glowing accents, and smooth hover effects.
- ❌ **Custom 404 Experience:** Playful movie-themed error handling for missing pages.

---

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Styling:** Tailwind CSS and DaisyUI
- **API:** TVMaze
- **Deployment:** Vercel
